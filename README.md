# PoE 2 國際市集與 FilterBlade 繁中

同一個 Tampermonkey 腳本支援 PoE 2 國際市集和 FilterBlade 的 PoE 2 模式。市集可用繁中或英文搜尋物品與詞綴。FilterBlade 可翻譯介面和物品名稱，也可用右下角「繁中」面板查物品英文名。

## 安裝與更新

1. 在瀏覽器安裝 Tampermonkey。
2. 開啟[安裝腳本](https://raw.githubusercontent.com/jackyuan987/poe2-trade-zh-hant/main/release/poe2-trade-zh-hant.user.js)，選擇「安裝」或「更新」。從此網址安裝過的人會依 Tampermonkey 的設定收到 v0.1.13。這次加入 FilterBlade 網域，可能會要求按一次「更新」。
3. 重新整理[國際服市集](https://www.pathofexile.com/trade2/search/poe2)和 [FilterBlade](https://www.filterblade.xyz/?game=Poe2)。若已安裝獨立版 FilterBlade 繁中腳本，請在 Tampermonkey 停用舊版。

在 FilterBlade 使用右下角「繁中」面板開關翻譯、設定中英對照或查物品英文名。按住 Alt 可暫時查看原文。合併版會在 FilterBlade 網站儲存偏好，原本使用獨立版的人可在面板重新設定。面板查到的英文物品名稱可複製到 FilterBlade 原生搜尋欄。

物品名稱以繁中遊戲客戶端資料為主。這是非官方腳本。
