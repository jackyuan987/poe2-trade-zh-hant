# PoE 2 國際市集詞綴繁中

在國際服 PoE 2 市集使用繁體中文搜尋物品和詞綴。結果卡片會顯示對應的遊戲繁中名稱、詞綴和實際數值，進階篩選面板也有繁中標籤。英文關鍵字也可使用。

## 安裝與更新

1. 在瀏覽器安裝 Tampermonkey。
2. 開啟[安裝腳本](https://raw.githubusercontent.com/jackyuan987/poe2-trade-zh-hant/main/release/poe2-trade-zh-hant.user.js)，在 Tampermonkey 按「安裝」。如果曾手動貼上舊版，請用此連結重新安裝一次。
3. 重新整理[國際服市集](https://www.pathofexile.com/trade2/search/poe2)。在「搜尋物品」輸入「琥珀護身符」，或按「顯示篩選」後搜尋「火焰抗性」等詞綴。

從上方連結安裝後，Tampermonkey 會依你的更新設定檢查 GitHub 上的版本。

物品名稱與藍裝命名格式來自遊戲客戶端。v0.1.4 將國際服詞綴目錄逐條比對 GGPK，7,723 個詞綴候選採用遊戲繁中，592 個待核對的候選保留英文。這是非官方腳本。
